# Forecast Agent AI

An Anthropic-powered time-series forecasting agent that reads CSV data, computes
point estimates, confidence intervals, and scenario narratives, then writes a
Markdown report.

## Features

- **Three forecasting methods** — Simple Moving Average, Linear Trend (OLS),
  Single Exponential Smoothing
- **80 % confidence intervals** — horizon-scaled using historical first-differences
- **Three scenarios** — optimistic (+15 %), base, pessimistic (-15 %)
- **Narrative Markdown report** — generated by Claude from structured forecast data
- **CLI** — one command, no boilerplate
- **No heavy ML deps** — models module uses only the standard library

## Installation

```bash
pip install forecast-agent-ai
# or from source:
git clone <repo>
cd forecast-agent-ai
pip install -e .
```

Set your Anthropic API key:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

## Quick Start

### CLI

```bash
forecast data.csv \
  --date-col date \
  --value-col revenue \
  --periods 12 \
  --method sma \
  --output forecast.md
```

**Options**

| Flag | Default | Description |
|---|---|---|
| `--date-col` | `date` | Date/time column name |
| `--value-col` | `value` | Numeric column to forecast |
| `--periods` | `12` | Future periods to forecast |
| `--method` | `sma` | `sma` \| `linear_trend` \| `exponential_smoothing` |
| `--output` | `forecast.md` | Output Markdown report path |
| `--api-key` | `$ANTHROPIC_API_KEY` | Override the API key |

### Python API

```python
from forecast_agent import ForecastAgent

agent = ForecastAgent()   # reads ANTHROPIC_API_KEY from env

reply = agent.run(
    csv_path="data.csv",
    date_col="date",
    value_col="revenue",
    periods=12,
    output_path="forecast.md",
    method="linear_trend",
)
print(reply)
```

## Input CSV Format

Any CSV with a date column and a numeric value column:

```csv
date,revenue
2023-01-01,120000
2023-02-01,135000
2023-03-01,128000
...
```

## Forecasting Methods

| Method | Key | Description |
|---|---|---|
| Simple Moving Average | `sma` | Mean of recent observations; flat forecast; best for stable series |
| Linear Trend (OLS) | `linear_trend` | Fits a straight line and extrapolates; best for trending series |
| Exponential Smoothing | `exponential_smoothing` | Weights recent data more; adapts to level shifts |

## Output Report Structure

The Markdown report written to `--output` includes:

1. Executive summary
2. Historical data overview
3. Methodology explanation
4. Forecast table (pessimistic / base / optimistic + 80 % CI)
5. Scenario narratives
6. Caveats and assumptions

## Architecture

```
forecast_agent/
  __init__.py      # public API (ForecastAgent)
  agent.py         # ForecastAgent class + tool schemas + dispatcher
  models.py        # pure-Python SMA, linear trend, exponential smoothing, CI
  cli.py           # Click + Rich CLI (forecast entry-point)
```

The agent uses Claude `claude-sonnet-4-6` with a manual tool-use loop:

```
User prompt
  └─> Claude (may call tools)
        ├─> read_csv   — loads and summarises the CSV
        ├─> compute_forecast — runs the chosen model, returns JSON
        └─> write_file — persists the Markdown report
  └─> Claude (end_turn) — returns narrative summary
```
